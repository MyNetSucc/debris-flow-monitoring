# Local detection pipeline dependencies.
#
# requirements.txt covers only the FastAPI dashboard that Render deploys; it
# deliberately excludes these because the cloud service never runs inference.
#
#   pip install -r requirements-detector.txt
#
# ---------------------------------------------------------------------------
# DO NOT pin torch here, and do not let pip install it as a side effect.
#
# torch/torchvision must match the CUDA runtime on the machine. The wheels on
# PyPI are frequently CPU-only, so a plain `pip install torch` can silently
# replace a working GPU build with one where torch.cuda.is_available() is
# False, and desync torchvision at the same time. Install it deliberately for
# your CUDA version, e.g.:
#
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
#
# Verify afterwards:
#   python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
#
# Known-good on this machine (conda env "yolo-ultra", RTX 3080 Ti):
#   torch 2.5.1 + torchvision 0.20.1, CUDA 12.1
# ---------------------------------------------------------------------------

# Lower bounds only, so installing this never downgrades a working environment.
